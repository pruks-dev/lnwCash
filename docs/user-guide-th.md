# LNWCASH Wallet — คู่มือการใช้งาน

LNWCASH Wallet คือกระเป๋าเงินดิจิทัลบน Lightning Network ที่ใช้โปรโตคอล Cashu — ให้คุณรับ-จ่าย-โอน ecash ได้โดยไม่ต้องเปิด Lightning node เอง ทำงานบนเว็บและมือถือ ฝั่งผู้ใช้ล้วน ๆ ไม่มีเซิร์ฟเวอร์กลาง

---

## เริ่มต้นใช้งาน

### 1. ติดตั้ง
- **Android**: โหลดไฟล์ APK แล้วติดตั้งด้วยตัวเอง (Sideload) — ยังไม่ขึ้น Play Store
- **iOS / Desktop**: เปิดผ่านเบราว์เซอร์ที่ `https://wallet.lnw.cash` หรือรัน PWA จากหน้าจอหลัก

### 2. สร้างรหัส PIN
เปิดแอปครั้งแรก ระบบจะให้ตั้ง PIN 4 หลัก PIN นี้ใช้ทั้งปลดล็อกกระเป๋าและเป็นกุญแจเข้ารหัส private key — จำเป็นต้องจำให้ได้ เพราะถ้าลืม **กู้คืนไม่ได้** (ดูหัวข้อ seed phrase)

### 3. ตั้งชื่อกระเป๋า + เพิ่ม Mint
- ตั้งชื่อกระเป๋าตามสะดวก (เช่น "ของฉัน", "ใช้จ่ายประจำ")
- เพิ่ม Mint URL — Mint คือเซิร์ฟเวอร์ที่ออก ecash ให้คุณ ต้องมีอย่างน้อย 2 Mint
- Mint สำหรับทดสอบ: `https://mint.lnw.cash`
- เลือก Keyset ที่ตรงกับหน่วยเงิน (ปกติจะเป็น `sat`)

### 4. ปลดล็อก
เข้าแอปทีหลัง → ป้อน PIN → เข้ากระเป๋าได้ทันที

## ฟีเจอร์หลัก

### 💰 ดูยอดเงิน (Balance)
- แสดงยอดรวมทุก Mint เป็น sats
- กดดูแยกตาม Mint ได้
- ปุ่มรีเฟรชอัปเดตยอด
- Badge สีเขียว (ออนไลน์) / สีแดง (ออฟไลน์) บอกสถานะเชื่อมต่อ

### 📥 รับเงิน (Receive)
1. ไปที่แท็บ **รับ**
2. ป้อน Lightning invoice หรือสแกน QR
3. กด **รับ (Mint)**
4. ระบบจะส่งคำขอไปที่ Mint → Mint จ่าย Lightning invoice ให้ → คุณได้รับ ecash
5. ดูจำนวนที่ได้รับและจำนวน proofs ได้หลังทำรายการเสร็จ

### 📤 จ่ายเงิน (Pay)
1. ไปที่แท็บ **จ่าย**
2. ป้อน invoice ที่ต้องการจ่าย (หรือสแกน QR)
3. ระบบแสดงยอด + ค่าธรรมเนียมก่อนยืนยัน
4. กด **จ่าย** → ระบบเลือก proofs ที่มี → ส่งไป mint → ได้ change คืนถ้ามียอดเกิน
5. ถ้าเงินไม่พอ ระบบจะแจ้งว่า "เงินไม่พอ"

### 🔄 โอน ecash แบบ P2P (Transfer)
- **ส่ง**: เลือก mint → ใส่จำนวน → กดสร้าง token → ได้ token string + QR code → แชร์ให้ผู้รับ
- **รับ**: เปิดแท็บรับ → วาง token string → ระบบตรวจสอบโครงสร้าง → เพิ่มเข้า wallet
- โอน ecash โดยไม่ต้องต่อเน็ตก็ได้ (sender สร้าง token ฝั่งผู้ใช้ล้วน ๆ)

### 📋 ประวัติธุรกรรม (History)
- แสดงรายการ Mint / Melt / โอน ทั้งหมด
- กรองตามประเภทได้
- ดูวันที่ จำนวน และสถานะ (สำเร็จ / รอดำเนินการ / ล้มเหลว)
- ข้อมูลเก็บใน IndexedDB — ดูได้แม้ offline

## สำรอง Seed Phrase (12 คำ)

Seed phrase คือกุญแจสำรองเข้ากระเป๋า — **เก็บให้ดีที่สุด** เพราะถ้าเครื่องหายหรือล้างข้อมูล แล้วไม่มี seed → เงินหายถาวร

> **โน้ต:** กระเป๋าที่สร้างใหม่ใช้ seed phrase 12 คำ (BIP39) ส่วนกระเป๋าเก่า (legacy) ใช้ 24 คำ — ยังกู้คืนได้เหมือนเดิม

### วิธี Export
1. ไปที่ตั้งค่า → Export Seed
2. ป้อน PIN อีกครั้งเพื่อยืนยันตัวตน
3. ระบบจะแสดง 12 คำภาษาอังกฤษ (BIP-39)
4. **จดลงกระดาษ** หรือเก็บในที่ปลอดภัย — ห้าม screenshot, ห้ามถ่ายรูป, ห้ามแชร์ให้ใคร

### ⚠️ คำเตือน
- Seed phrase = สิทธิ์เข้าถึงเงินทั้งหมด — ใครได้ seed ไป = ได้เงินไป
- LNWCASH ไม่เก็บ seed ให้ — เป็นความรับผิดชอบของคุณทั้งหมด
- ล้างข้อมูลเบราว์เซอร์โดยไม่มี seed → เงินหายถาวร ไม่สามารถกู้คืนได้

## คำถามที่พบบ่อย (FAQ)

### ecash คืออะไร
ecash คือเงินดิจิทัลที่ทำงานคล้ายธนบัตร — ถือไว้ในมือตัวเอง ไม่ต้องฝากใคร ใช้จ่ายได้โดยไม่ต้องเปิดเผยตัวตน ออกโดย Mint ที่เชื่อถือได้ผ่าน Lightning Network

### ถ้าเคลียร์ข้อมูลเบราว์เซอร์ เงินจะหายไหม
**หาย** — ecash เป็น bearer instrument (ใครถือ proofs อยู่ คนนั้นเป็นเจ้าของ) Proofs เก็บใน IndexedDB ของเบราว์เซอร์คุณเท่านั้น ถ้าเคลียร์โดยไม่ export seed → เงินหายถาวร

### ใช้ตอน offline ได้แค่ไหน
- ✅ ดูยอดคงเหลือ (อ่านจาก IndexedDB)
- ✅ ดูประวัติธุรกรรม
- ✅ สร้าง ecash token ส่งให้คนอื่นแบบ P2P
- ❌ Mint / Melt (ต้องต่อเน็ตเพื่อคุยกับ mint)
- ✅ Semi-verify token ที่รับมา (ตรวจสอบโครงสร้างเฉพาะที่)

### ทำไมต้องมี Mint URL มากกว่า 1 อัน
Mint แต่ละเจ้าอาจมีข้อจำกัดต่างกัน เช่น ค่าธรรมเนียม, ปริมาณสภาพคล่อง, หรือ downtime การมีหลาย Mint ช่วยให้ย้ายเงินข้าม mint ได้และไม่ผูกขาดกับเจ้าเดียว

### Mint URL หาได้จากที่ไหน
- ชุมชน Cashu มีรายชื่อ mint สาธารณะ
- `https://mint.lnw.cash` สำหรับนักพัฒนาและทดสอบ
- Mint ส่วนตัว หรือ mint ของเพื่อน
