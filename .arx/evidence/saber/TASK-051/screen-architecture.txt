# TASK-051 Screen Architecture (D-002)

## Consolidation: ~9 screens → 6 main routes

### New Screen Architecture (6 routes)

| Route      | Screen    | File                   | Description                                    |
|-----------|-----------|------------------------|------------------------------------------------|
| /         | Home      | screens/Home.svelte    | Dashboard: Balance + Quick Actions + Recent Tx |
| /receive  | Receive   | screens/Receive.svelte | Lightning invoice + QR + copy + share          |
| /send     | Send      | screens/Send.svelte    | Invoice input → confirm → melt flow            |
| /history  | History   | screens/History.svelte | Full tx list with date grouping                |
| /settings | Settings  | screens/Settings.svelte| Mint, Language, Theme, About sections          |
| /setup    | Setup     | screens/Setup.svelte   | Wallet setup: Register + CreateWallet          |
