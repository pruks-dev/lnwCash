Balance Update Implementation:

Receive.svelte:
  - updateBalanceDisplay() calls getBalance() after mint
  - Result displayed in success section via animated counter

Send.svelte:
  - refreshBalance() calls getBalanceByMint() after melt & token creation
  - Balance in IndexedDB updated by wallet core (proofsDb.addProofs/markSpent)

Wallet Core (no changes — already correct):
  - mint.ts → addProofs() stores minted proofs ✓
  - melt.ts → markSpent() + addProofs() handles change ✓
  - transfer.ts → markSpent() for send, addProofs() for receive ✓
  - balance.ts → getBalance() reads from getUnspentProofs() ✓

Net Balance:
  Mint (+5) → Balance: x + 5
  Melt (-10) → Balance: x + 5 - 10 = x - 5
  Send Cashu (-amt) → Balance: x - 5 - amt
  Receive Cashu (+amt) → Balance: x - 5 + amt

All balance operations are persisted to IndexedDB (IDB).
Wallet state is durable across page reloads.
