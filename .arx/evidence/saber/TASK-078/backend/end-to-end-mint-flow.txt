F-042 + F-043 + F-044 — End-to-End Mint Flow
================================================

1. SETUP (F-043 — Default Mint Pre-fill)
   → User opens app first time
   → PIN registration
   → Create wallet step: https://mint.lnw.cash pre-filled ✓
   → User can add another mint or remove default
   → Create wallet (needs >= 2 mints)

2. HOME
   → User on home screen after wallet creation
   → Bottom nav: Home | Receive | Send | History | Settings

3. SETTINGS → MANAGE MINT (F-042 — Routing Fix)
   → User clicks Settings → sees 'Manage Mint' in Mint section
   → Clicks 'Manage Mint' → MintSettings sub-view renders ✓
   → Sees active mint with details (name, version, NUTs) ✓
   → Sees mint list (other mints) ✓
   → Back button returns to Settings ✓

4. ADD MINT (F-044 — /v1/info Validation)
   → User clicks '+ Add Mint' 
   → Modal opens with URL input
   → User enters https://new.mint.example
   → Clicks 'Validate'
   → /v1/info called with 5s timeout
   → Success: mint name 'New Mint', version 'Nutshell/0.21.0', NUTs displayed
   → User clicks 'Add Mint' → mint added to list
   → OR Failure: error message displayed (timeout / unreachable / invalid)
   → User can retry with different URL

5. SWITCH MINT
   → User clicks on a mint in the list
   → discoverMintEndpoints called to verify
   → Active mint switches to selected mint
   → UI updates showing new active mint

All 3 fixes integrated: Setup pre-fill → Settings routing → Add validation
