## Heuristic behaviour (Nutshell >= 0.17 → assumed NUT-08)

Even when a mint omits NUT-08 from its `nuts` map, `hasNUT08()` returns `true` for any Nutshell version ≥ 0.17. This protects us against:
- mints that advertise `version` but skip the NUT-08 entry
- legacy mints that pre-date NUT-08 spec changes

`isVersionAtLeast(version, 0, 17)` accepts these shapes:
- `"Nutshell/0.20.1"` → `0.20` ≥ `0.17` → `true`
- `"0.16.0"` → `0.16` < `0.17` → `false`
- `"v0.18.0"` → `0.18` ≥ `0.17` → `true`
- `""` → unparseable → `false`
