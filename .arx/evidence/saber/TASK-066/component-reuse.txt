# Component Reuse Report — TASK-066

## New Reusable Components Created

### 1. Numpad.svelte (`src/lib/components/Numpad.svelte`)
- **Purpose**: Reusable numeric keypad for amount input
- **Props**: value, onchange, onconfirm, confirmLabel, maxDigits, maxDecimals, disabled
- **Features**: 0-9 digits, backspace (⌫ SVG icon), decimal point, confirm button
- **Touch**: 56px height buttons, scale(0.95) active feedback
- **Reused in**: Receive.svelte (Lightning tab), Send.svelte (Cashu tab)
- **Usage count**: 2 sites

### 2. QRDisplay.svelte (`src/lib/components/QRDisplay.svelte`)
- **Purpose**: Display QR code as SVG for invoices and tokens
- **Props**: data, size (default 200), label
- **Features**: Auto-generates QR via generateQrSvg(), renders as data URI <img>
- **Reused in**: Receive.svelte (invoice QR), Send.svelte (token QR)
- **Usage count**: 2 sites

### 3. qrcode.ts (`src/lib/util/qrcode.ts`)
- **Purpose**: Minimal QR Code (Model 2) SVG generator — byte-mode, EC level M
- **Exports**: generateQrSvg(), generateQrDataUri()
- **Features**: GF(256) math, auto-version selection (1-20), mask selection, SVG output
- **Used by**: QRDisplay.svelte
