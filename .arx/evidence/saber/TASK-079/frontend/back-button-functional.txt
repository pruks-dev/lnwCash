# F-051: Back button functional verification

## Back button behavior:

### Implementation:
```typescript
function handleBack() {
    window.history.back();
}
```

### Usage:
The same `handleBack` function is used in the inline back-header
for Send/Receive/Settings screens.

### Expected behavior:
1. User is on Send screen → clicks back button → window.history.back()
2. User is on Receive screen → clicks back button → window.history.back()
3. User is on Settings screen → clicks back button → window.history.back()

### Navigation flow:
```
Home → (tap Send tab) → Send screen     → (click ←) → Home
Home → (tap Receive tab) → Receive screen → (click ←) → Home
Home → (tap Settings tab) → Settings screen → (click ←) → Home
Home → (tap History tab) → History screen  → (click ←, TopAppBar showBack) → Home
```

### Accessibility:
- aria-label uses translation key 'common.back'
- Keyboard focusable (native <button>)
- Minimum touch target: 44x44px

✅ Back button returns to previous screen via browser history
